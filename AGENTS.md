# Setup commands
- Install deps: `npm ci`
- Build: `npm run build`

# Code style
- Single quotes, no semicolons
- Use functional patterns where possible

# Running the dev server
Start the dev server: `npm run start`

# Technologies
- TailwindCSS
- Node.js
- NPM
- Netlify

# Development
- Use the modern-web-guidance skill for best practices in developing web pages and javascript.
- When implementing a web page feature and modern-web-guidance is not available or doesn't apply, consult the MDN MCP server.
- For CSS layout and styling, opt to use TailwindCSS utility classes instead of writing custom CSS, unless a specific design requirement cannot be met with TailwindCSS.
